# PinkBulbTCG

Een persoonlijke Pokémon TCG-hobbysite, gebouwd met HTML, CSS en JavaScript.

## Bestanden

- `index.html` – inhoud en structuur van de website.
- `style.css` – kleuren, typografie, indeling en responsive vormgeving.
- `script.js` – interactie voor het mobiele navigatiemenu.

## Lokaal bekijken

Open `index.html` in je browser. Je hebt geen installatie of buildstap nodig.

## Publiceren via GitHub Pages

1. Maak op GitHub een nieuwe repository aan, bijvoorbeeld `pinkbulbtcg`.
2. Upload de bestanden uit deze map naar de hoofdmap van de repository.
3. Open in GitHub de repository-instellingen (**Settings**).
4. Ga naar **Pages**.
5. Kies bij **Build and deployment** voor **Deploy from a branch**.
6. Selecteer de branch `main` en map `/ (root)`.
7. Klik op **Save**. GitHub maakt daarna je website beschikbaar via de getoonde Pages-link.

## Nog aan te passen

De huidige pagina bevat nog voorbeeldinhoud en tijdelijke links. Vervang onder andere:
- voorbeeldblogs en voorbeelddata;
- voorbeeldbeurzen en evenementen;
- voorbeeldkaarten en prijzen;
- Instagram-link en eventuele Instagram-afbeeldingen;
- VaultX-link en eventuele affiliatevermelding;
- tekst bij 'Over mij' en je contactgegevens.

De website is een statische website. Blogberichten, kaarten en evenementen worden dus niet automatisch bijgewerkt vanuit een database of webshop; je past deze voorlopig rechtstreeks in `index.html` aan.

## Opmerking

De Google Fonts worden extern geladen. Zonder internetverbinding gebruikt de browser een alternatief lettertype.
