Master set, complete set en reverse holos

Wat is het verschil en hoe houd je bij welke kaarten nog ontbreken?

PinkBulbTCG · 11 november 2026

Een complete set betekent voor veel verzamelaars dat ze van elk kaartnummer uit een uitbreiding minimaal één exemplaar hebben. Maar de precieze definitie verschilt per verzamelaar.

Met een master set bedoelen verzamelaars vaak alle genummerde kaarten én de beschikbare varianten, zoals reverse holo's. Soms tellen ze ook promokaarten mee; anderen juist niet. Spreek daarom altijd af wat jij onder een master set verstaat.

Controleer een setlijst en maak een checklist van wat je al hebt. Let op verschillende afwerkingen met hetzelfde nummer, speciale illustratiekaarten en eventuele kaarten buiten de gewone nummering.

Je kunt je voortgang bijhouden in een spreadsheet, op papier of in een collectie-app. Via mijn DEX-affiliatelink kun je de app bekijken: https://app.dextcg.com/welcome/?aff=amanda .

Mijn tip: begin met een set die je écht leuk vindt. Het verzamelen moet plezier geven, geen verplichting worden.
